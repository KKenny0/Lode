# 技能

Lode 包含七个技能。每个技能相互独立 — 可以单独安装，也可以全部使用。它们共享一套本地存储约定，使下游报告可以复用早期上下文。

## 冷启动访谈

**触发：** `/lode:cold-start-interview`

首次运行配置。创建 `~/.lode/config.yaml`，包含：
- 知识库路径（Lode 存储数据的位置）
- 项目标识和 slug
- 报告语言（英语、中文或混合）
- 周报模式和团队上下文

运行一次即可。之后所有技能会自动读取配置。

## Recall（回忆）

**触发：** `/lode:recall`、`开工`、`session start`、`继续上次`

会话开始时的上下文回忆。从知识库读取最近的原始条目和制品索引，呈现：
- 最近的决策及其理由
- 开放的风险和未解决的问题
- 值得记住的放弃方案
- 可能需要关注的过期意图制品

无 vault 也可用 — 退回到纯对话上下文。

## Capture（捕获）

**触发：** `/lode:capture`、`收工`、`done`、`今天到这`

自适应深度会话回顾。将会话分为五种原型之一：
- **决策** — 设计选择、权衡、放弃的路径
- **构建** — 实现的功能、变更的契约
- **调查** — 探索、发现、死胡同
- **修复** — 修复的 bug、根因、缓解措施
- **维护** — 重构、升级、清理

写入报告级别的信号（决策、风险、契约、影响），而非过程日志。还会生成架构文档、计划和 README 文件的轻量同步建议。

零配置模式：直接在对话中输出结构化 Markdown，无需写入任何 vault。

## Daily（日报）

**触发：** `/lode:daily`、`更新日报`、`日报`、`daily note`

从原始条目和 git 历史更新 Obsidian 日报。将多个会话的活动聚合为单日视图。

## Weekly（周报）

**触发：** `/lode:weekly`、`周报`、`weekly PPT`

从原始变更条目构建周报大纲。以原始条目作为主要语义来源；git 日志仅作为补充和覆盖证据。当存在相关证据时，包含条件性的「困难章节」。

## Monthly（月度回顾）

**触发：** `/lode:monthly`、`月度回顾`、`月报`、`monthly review`

从日报生成月度回顾。提取信号、生成结构化骨架，并从重复证据中提出候选规则。Python 脚本处理解析和聚合，确保确定性。

## Roadmap（路线图）

**触发：** `/lode:roadmap`、`决策路线图`、`decision roadmap`

从积累的原始条目生成叙事性决策路线图。追踪：
- 已做出的决策及其背景
- 未解决的累积风险
- 反复出现的开放问题
- 思维方式的演变过程

路线图不是功能列表 — 它讲述发生了什么以及为什么。
