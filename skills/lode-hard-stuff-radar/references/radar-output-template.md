# Hard Stuff Radar Output Template

```markdown
## Hard Stuff Radar — {project}

### Recurring Open Questions
- {question}
  Evidence: {timestamps}

### Architecture Or Contract Risks
- {risk}
  Evidence: {timestamps or artifact ids}

### Abandoned Alternatives Worth Revisiting
- {alternative}
  Why revisit: {condition that changed or unresolved assumption}

### Maintenance Debt Signals
- {signal}

### Needs More Than Code
- {problem}: needs {tests/design/research/human judgment}
```

Use "Inferred" when evidence is weak.
