# Experience Distillation Contract

## Evidence Strength

- **Strong**: two or more raw entries show the same risk, question, or decision
  pattern, or one high-impact entry plus an artifact index reference.
- **Medium**: one explicit risk/decision entry with clear impact.
- **Weak**: one old-schema entry inferred from summary/context only.

## Output Targets

Choose the smallest reusable artifact:

- Checklist item for local repeated reminders.
- AGENTS.md rule for repo-wide agent behavior.
- Skill update for recurring workflow across repos.
- Debugging playbook for repeated failure paths.
- Prompt/schema contract note for interface-level lessons.

## Write Policy

All writes require approval unless the user explicitly requests write mode. In
write mode, update only approved targets and append a raw `decision` entry when
the distillation changes future workflow.
